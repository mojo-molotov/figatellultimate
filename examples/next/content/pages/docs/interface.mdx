# Interface

Trois couches, chacune facultative : `@figatellultimate/ui`, un design system minimal ; `@figatellultimate/effects`, des effets décoratifs ; `@figatellultimate/themes`, des thèmes par-dessus les deux. Leurs composants n’ont aucun texte à eux : chaque libellé vient de vos messages, dans la langue du lecteur.

```sh npm
npm install @figatellultimate/ui @figatellultimate/effects @figatellultimate/themes react radix-ui
```

```sh pnpm
pnpm add @figatellultimate/ui @figatellultimate/effects @figatellultimate/themes react radix-ui
```

```sh yarn
yarn add @figatellultimate/ui @figatellultimate/effects @figatellultimate/themes react radix-ui
```

```sh bun
bun add @figatellultimate/ui @figatellultimate/effects @figatellultimate/themes react radix-ui
```

## Le design system

| Composant               | Rôle                                                                                                                                                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Navbar`                | La navigation générée depuis le contenu (`navigationOf(locale)`), avec ses menus ; compacte, derrière un bouton, dès que ses liens ne tiennent plus sur une ligne (`navbarScript` avant le premier affichage). |
| `LocaleSwitcher`        | La page dans les autres langues, jamais un lien vers une traduction manquante.                                                                                                                                 |
| `ThemeToggle`           | Clair et sombre, avec `themeScript` appliqué avant le premier affichage ; son nom dit le thème actuel et celui que donne l’appui.                                                                              |
| `SiteThemePicker`       | Le choix entre plusieurs thèmes du site, avec `siteThemeScript` avant le premier affichage et `stylesheetBase` pour charger les thèmes secondaires à la demande.                                               |
| `Breadcrumb`            | Où se situe la page, d’après la navigation (`formatTrail` et `parseTrail` de `@figatellultimate/site` la résument pour la recherche).                                                                          |
| `TableOfContents`       | Les titres de la page, celui qu’on lit en surbrillance, ancrée dans la marge à partir de `TOC_WIDE_MEDIA` ; son bouton peut avoir son propre nom (`toggle`).                                                   |
| `EntryCard`             | L’aperçu d’un billet : image, titre, date, tags, auteurs ; son titre au niveau que la page lui donne (`headingLevel`, h2 par défaut).                                                                          |
| `CodeBlock`, `CodeTabs` | Un bloc de code avec son bouton de copie ; les variantes d’un même bloc en onglets, le choix du lecteur retenu sous `storageKey`.                                                                              |
| `ImageZoom`             | Une image agrandie dans une fenêtre sur ordinateur (`media`, `IMAGE_ZOOM_MEDIA` par défaut).                                                                                                                   |
| `ScrollRegion`          | Une zone qui défile seule (un tableau large), dans l’ordre de tabulation tant qu’elle déborde seulement.                                                                                                       |
| `PrintMargins`          | Pose `--fig-print-title` et `--fig-print-url` sur `:root` pour les boîtes de marge `@page` à l’impression.                                                                                                     |
| `UiProvider`            | Fournit en une fois les composants de lien et d’image du framework (`LinkProvider` et `ImageProvider`).                                                                                                        |

Une seule feuille de styles les met tous en forme, par des attributs `data-slot` et des tokens :

```css
@import '@figatellultimate/ui/styles.css';

:root {
  --fig-accent: #0f766e;
  --fig-radius: 4px;
}
```

Chaque token a une valeur sombre, sous `prefers-color-scheme: dark` et sous `data-theme="dark"`. Sur papier, chaque page s’imprime en noir sur blanc, sans la navigation.

## Les effets

`Effects` charge une lueur sous le curseur et des particules dans les marges, sur ordinateur seulement, jamais côté serveur ni sur téléphone ; `Collector` éclaire une carte sous la souris ; `Reveal` dévoile le pied de page sous la page. Chaque apparence est un token : `--fig-glow-color`, `--fig-sparkles-column`, `--fig-collector-color`.

```tsx
import '@figatellultimate/effects/styles.css';
import { Effects, Reveal } from '@figatellultimate/effects';

<body>
  {children}
  <Reveal>
    <footer>…</footer>
  </Reveal>
  <Effects />
</body>;
```

## Les thèmes

`base.css` met en page le site : la colonne du texte, l’article et son sommaire, les listes, la typographie du MDX, l’impression. Un thème par-dessus ne règle que son apparence. **maquis** pose du verre sombre sur les aperçus, le code et les tableaux, et montre les effets en thème sombre. **calanque** associe une barre bleu marine profond, des cartes blanches élevées sur un fond à grain léger en thème clair, et une nuit bleu marine en thème sombre, sans aucun effet.

```tsx
import '@figatellultimate/ui/styles.css';
import '@figatellultimate/effects/styles.css';
import '@figatellultimate/themes/base.css';
import '@figatellultimate/themes/calanque.css';
```

Plusieurs thèmes peuvent coexister : `<html data-site-theme="calanque">` en choisit un. Sans cet attribut, un thème chargé seul s’applique. Ce site charge **maquis** par défaut et sert **calanque** à la demande (`/themes/calanque.css`, via `themeStylesheetRoute`) ; son pied de page laisse le lecteur basculer avec `SiteThemePicker` (`stylesheetBase="/themes/"`), le changement flouté le temps d’une transition par `siteThemeTransition` de `@figatellultimate/effects`.
