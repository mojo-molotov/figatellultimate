# Quick start

In a few minutes: a Next.js site whose pages are MDX files in a folder, every page checked at build time and served by one route.

## 1. Create the project

```sh npm
npx create-next-app my-site
cd my-site
```

```sh pnpm
pnpm create next-app my-site
cd my-site
```

```sh yarn
yarn create next-app my-site
cd my-site
```

```sh bun
bun create next-app my-site
cd my-site
```

## 2. Install figatellultimate

The CLI, the core and the adapter of Content Collections, which reads the frontmatter and compiles the MDX:

```sh npm
npm install -D @figatellultimate/cli @figatellultimate/core @figatellultimate/content-collections @content-collections/core
npm install @content-collections/mdx valibot
```

```sh pnpm
pnpm add -D @figatellultimate/cli @figatellultimate/core @figatellultimate/content-collections @content-collections/core
pnpm add @content-collections/mdx valibot
```

```sh yarn
yarn add -D @figatellultimate/cli @figatellultimate/core @figatellultimate/content-collections @content-collections/core
yarn add @content-collections/mdx valibot
```

```sh bun
bun add -d @figatellultimate/cli @figatellultimate/core @figatellultimate/content-collections @content-collections/core
bun add @content-collections/mdx valibot
```

## 3. Describe the content

Content Collections reads and validates the files:

```ts
// content-collections.ts
import { defineCollection, defineConfig } from '@content-collections/core';
import { compileMDX } from '@content-collections/mdx';
import { withFigatellultimate } from '@figatellultimate/content-collections/config';
import * as v from 'valibot';

const pages = withFigatellultimate(
  defineCollection({
    name: 'pages',
    directory: 'content/pages',
    include: '**/*.mdx',
    schema: v.object({ title: v.string(), content: v.string() }),
    transform: async (document, context) => ({ ...document, mdx: await compileMDX(context, document) }),
  }),
);

export default defineConfig({ content: [pages] });
```

For a table of contents and tabbed code blocks, `compileWithHeadings` of `@figatellultimate/content-collections/config` compiles the MDX with its headings, cached together, and `rehypeCodeGroups` groups the blocks marked `npm`, `pnpm`, `yarn` or `bun` as tabs (`CodeTabs`).

figatellultimate says what the folders mean:

```ts
// figatellultimate.config.ts
import { join } from 'node:path';

import { createContentCollectionsSource } from '@figatellultimate/content-collections';
import { defineCollection, defineConfig, defineLocales, locale, rest, slug } from '@figatellultimate/core';

export default defineConfig({
  locales: defineLocales({ list: ['en'], default: 'en' }),
  collections: {
    pages: defineCollection({
      entry: 'page',
      base: '',
      grammar: [locale({ optional: true }), rest('path'), slug()],
      metadata: { title: 'title' },
    }),
  },
  source: createContentCollectionsSource({
    configPath: join(import.meta.dirname, 'content-collections.ts'),
    projectRoot: import.meta.dirname,
  }),
});
```

## 4. Write a page

`content/pages/index.mdx` is the home page, `content/pages/guide/setup.mdx` would be `/guide/setup`:

```mdx
---
title: 'Hello'
---

# Hello

My first page, written in MDX.
```

## 5. Import the generated code

In `package.json`, the alias of the generated code; add `.figatellultimate/` to `.gitignore`:

```json
{
  "type": "module",
  "imports": { "#figatellultimate/*": "./.figatellultimate/*/index.js" }
}
```

## 6. One route for every page

```tsx
// app/[[...url]]/page.tsx
import { MDXContent } from '@content-collections/mdx/react';
import { notFound } from 'next/navigation';

import { findByUrl, mountedUrls, segmentsOf, urlOf } from '#figatellultimate/urls';

export const dynamicParams = false;

export function generateStaticParams() {
  return mountedUrls.map((item) => ({ url: segmentsOf(item.url, item.locale) }));
}

export default async function Page(props: PageProps<'/[[...url]]'>) {
  const { url } = await props.params;
  const found = await findByUrl(urlOf('en', url));

  if (found?.kind !== 'entry') notFound();

  return <MDXContent code={found.entry.data.mdx} />;
}
```

## 7. Build and run

```sh npm
npx figatellultimate build
npx next dev
```

```sh pnpm
pnpm figatellultimate build
pnpm next dev
```

```sh yarn
yarn figatellultimate build
yarn next dev
```

```sh bun
bunx figatellultimate build
bunx next dev
```

`figatellultimate build` checks every file and writes `.figatellultimate/`; a page asked for that does not exist does not compile. To rebuild on every change, run `figatellultimate watch` next to the dev server.
