# Command line

`@figatellultimate/cli` installs the `figatellultimate` command. Run it at the project’s root, where `figatellultimate.config.ts` lives.

## Commands

| Command                    | Does                                                                              |
| -------------------------- | --------------------------------------------------------------------------------- |
| `figatellultimate build`   | Analyzes the content and writes the generated code to `.figatellultimate/`.       |
| `figatellultimate check`   | The same analysis, writing nothing: for continuous integration.                   |
| `figatellultimate watch`   | Builds, then rebuilds on every change of the content, the config or the messages. |
| `figatellultimate search`  | Indexes the built site with Pagefind, one bundle per language.                    |
| `figatellultimate migrate` | Moves the content to another default language or notation.                        |

```sh npm
npx figatellultimate build
npx figatellultimate watch
```

```sh pnpm
pnpm figatellultimate build
pnpm figatellultimate watch
```

```sh yarn
yarn figatellultimate build
yarn figatellultimate watch
```

```sh bun
bunx figatellultimate build
bunx figatellultimate watch
```

## Options

| Option                  | Effect                                                                                                                       |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `-c`, `--config <path>` | The config file (default `figatellultimate.config.ts`).                                                                      |
| `-m`, `--mode <mode>`   | `production` (default for build and check) leaves drafts and test content out; `development` (default for watch) keeps them. |
| `--site <path>`         | search: the built HTML.                                                                                                      |
| `--out <path>`          | search: where to write the bundles (default `public/pagefind`).                                                              |
| `--locale-folders`      | search: every language is built in its own folder, the default one included.                                                 |
| `--no-unused`           | build, check: skip the scan of the messages no code uses, which compiles the application.                                    |
| `--write`               | migrate: apply the plan.                                                                                                     |
| `-h`, `--help`          | Show the help.                                                                                                               |
| `-v`, `--version`       | Show the version.                                                                                                            |

## Exit codes

| Code | Meaning                                                                 |
| ---- | ----------------------------------------------------------------------- |
| `0`  | No error.                                                               |
| `1`  | Content errors, each reported with its file.                            |
| `2`  | An invalid config or a usage error, the help printed after the problem. |
| `3`  | An unexpected failure.                                                  |

## Watching

`watch` serializes its runs: a change during a build cancels it and starts a fresh one, and the last valid generated code stays in place until the new one succeeds. It stops cleanly on Ctrl+C or SIGTERM.

## Migrations

`migrate` changes the default language, or the notation (implicit or explicit language folders). Without `--write`, it prints its plan; with it, it moves every file, edits the config and writes `redirects.json`, all or nothing:

```sh npm
npx figatellultimate migrate default-locale en
npx figatellultimate migrate default-locale en --write
```

```sh pnpm
pnpm figatellultimate migrate default-locale en
pnpm figatellultimate migrate default-locale en --write
```

```sh yarn
yarn figatellultimate migrate default-locale en
yarn figatellultimate migrate default-locale en --write
```

```sh bun
bunx figatellultimate migrate default-locale en
bunx figatellultimate migrate default-locale en --write
```

The redirects are composed with the previous ones: an old link reaches its page in one hop, whatever the number of migrations.
