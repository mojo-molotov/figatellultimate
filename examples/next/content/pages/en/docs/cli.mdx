# Command line

`@figatellu/cli` installs the `figatellu` command. Run it at the project’s root, where `figatellu.config.ts` lives.

## Commands

| Command             | Does                                                                              |
| ------------------- | --------------------------------------------------------------------------------- |
| `figatellu build`   | Analyzes the content and writes the generated code to `.figatellu/`.              |
| `figatellu check`   | The same analysis, writing nothing: for continuous integration.                   |
| `figatellu watch`   | Builds, then rebuilds on every change of the content, the config or the messages. |
| `figatellu search`  | Indexes the built site with Pagefind, one bundle per language.                    |
| `figatellu migrate` | Moves the content to another default language or notation.                        |

```sh npm
npx figatellu build
npx figatellu watch
```

```sh pnpm
pnpm figatellu build
pnpm figatellu watch
```

```sh yarn
yarn figatellu build
yarn figatellu watch
```

```sh bun
bunx figatellu build
bunx figatellu watch
```

## Options

| Option                  | Effect                                                                                                                       |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `-c`, `--config <path>` | The config file (default `figatellu.config.ts`).                                                                             |
| `-m`, `--mode <mode>`   | `production` (default for build and check) leaves drafts and test content out; `development` (default for watch) keeps them. |
| `--site <path>`         | search: the built HTML.                                                                                                      |
| `--out <path>`          | search: where to write the bundles (default `public/pagefind`).                                                              |
| `--locale-folders`      | search: every language is built in its own folder, the default one included.                                                 |
| `--write`               | migrate: apply the plan.                                                                                                     |

## Exit codes

| Code | Meaning                                                                 |
| ---- | ----------------------------------------------------------------------- |
| `0`  | No error.                                                               |
| `1`  | Content errors, each reported with its file.                            |
| `2`  | An invalid config or a usage error, the help printed after the problem. |
| `3`  | An unexpected failure.                                                  |

## Watching

`watch` serializes its runs: a change during a build cancels it and starts a fresh one, and the last valid generated code stays in place until the new one succeeds. It stops cleanly on Ctrl+C or SIGTERM.

## Migrations

`migrate` changes the default language, or the notation (implicit or explicit language folders). Without `--write`, it prints its plan; with it, it moves every file, edits the config and writes `redirects.json`, all or nothing:

```sh npm
npx figatellu migrate default-locale en
npx figatellu migrate default-locale en --write
```

```sh pnpm
pnpm figatellu migrate default-locale en
pnpm figatellu migrate default-locale en --write
```

```sh yarn
yarn figatellu migrate default-locale en
yarn figatellu migrate default-locale en --write
```

```sh bun
bunx figatellu migrate default-locale en
bunx figatellu migrate default-locale en --write
```

The redirects are composed with the previous ones: an old link reaches its page in one hop, whatever the number of migrations.
