# Accueil

Bienvenue sur figatellultimate : vos fichiers MDX deviennent un site typé, traduit et vérifié dès le build.

Créez un dossier, lancez le build, suivez les diagnostics : la structure, les URL et les traductions à fournir viennent des chemins de vos fichiers.
